# 매직버킷

https://treno87.github.io/ — Jekyll + [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) 블로그.

## 글 쓰기

1. `_posts/YYYY-MM-DD-slug.md` 파일을 만든다 (Obsidian 볼트 `~/Projects/Treno87.github.io` 의 `_posts` 폴더, 템플릿: `_templates/post.md`).
2. 이미지는 `images/` 아래에 두고 `/images/...` 로 링크한다.
3. `blog-publish` 로 커밋·푸시하면 1분 안에 사이트에 반영된다.
